================================================================================
Resend メール自動送信システム セットアップ手順書
================================================================================



================================================================================
📋 概要：現在のシステムについて
================================================================================

【現在の設定状況】
- 送信元メールアドレス：noreply@your-domain.com など（クライアントのドメイン）
- API キー：システムサーバーに保管
- メール テンプレート：システムに組み込み済み


================================================================================
🔧 セットアップ手順
================================================================================

▼ ステップ 1：メールアドレスを作成する

独自ドメイン用の「送信専用メールアドレス」を作成します。
（例：noreply@yourdomain.com や support@yourdomain.com）

【メールプロバイダー側での設定】
お客様が利用しているメールサービス（Google Workspace、Microsoft 365、さくらメール等）で
以下の手順を実施してください：

1. 管理画面にログイン
   - Google Workspace の場合：https://admin.google.com
   - Microsoft 365 の場合：https://admin.microsoft.com
   - その他のサービス：各プロバイダーの管理画面へ

2. 新しいメールアドレスを作成
   - 例：noreply@yourdomain.com
   - 例：support@yourdomain.com
   - 別途アカウントを作成するか、エイリアスを設定してください

3. パスワードを設定（別途アカウント作成時）
   - 安全なパスワードを設定してください


▼ ステップ 2：Resend に登録する

1. Resend のウェブサイトにアクセス
   - URL: https://resend.com
   - 右上の「Sign Up」ボタンをクリック

2. アカウントを作成
   - メールアドレスを入力
   - パスワードを設定
   - 「Create account」をクリック

3. メール認証を完了
   - Resend から確認メールが届きます
   - メール内のリンクをクリックして認証完了

4. ダッシュボードにログイン
   - 認証後、Resend のダッシュボードが表示されます


▼ ステップ 3：Resend にドメインを追加する

1. ダッシュボードから「Domains」を選択
   - 左側メニューの「Domains」をクリック

2. 「Add Domain」ボタンをクリック
   - 画面右側の青い「Add Domain」ボタンをクリック

3. ドメインを入力
   入力欄に独自ドメインを入力してください
   例：yourdomain.com

   ⚠️ サブドメインは不要です（yourdomain.com でOK）

4. DNS レコードを確認
   Resend から以下の 2～3 個の DNS レコード情報が表示されます：

   - SPF レコード
   - DKIM レコード（複数の場合あり）
   - CNAME レコード（セットアップの場合のみ）

   これらをコピーして、次のステップで使用します


▼ ステップ 4：DNS レコードを設定する

このステップは、ドメインを管理しているサービス側で実施します。

【使用しているドメイン管理サービスを確認】
- お名前.com を使用している場合
- Google Domains を使用している場合
- ムームードメイン を使用している場合
- その他のレジストラ を使用している場合


【パターンA: お名前.com でドメイン管理している場合】

1. お名前.com にログイン
   - URL: https://www.onamae.com
   - 上部の「ログイン」ボタンからログイン

2. ドメイン管理画面にアクセス
   - 左側メニューの「ドメイン一覧」をクリック

3. 対象ドメインを選択
   - あなたのドメインをクリック
   - 「ネームサーバーを変更する」をクリック

4. DNS レコードを追加
   - 「DNSレコード」や「DNS 設定」タブをクリック
   - Resend から提供されたレコードを入力

   【設定例】
   レコード種別 | ホスト名 | 内容
   -------------------------------------------
   SPF | @ | v=spf1 include:sendingdomain.resend.dev ~all
   DKIM | default._domainkey | [Resend から提供される値]
   CNAME | (指定されている場合) | [Resend から提供される値]

5. 保存
   - 「確認」→「完了」をクリック


【パターンB: Google Domains でドメイン管理している場合】

1. Google Domains にログイン
   - URL: https://domains.google.com

2. ドメイン管理画面にアクセス
   - 対象ドメインをクリック

3. DNS ページを開く
   - 左側メニューの「DNS」をクリック

4. カスタムレコードを追加
   - 下部の「カスタムレコードを管理」をクリック
   - Resend から提供されたレコードを入力

5. 保存
   - 設定が自動保存されます


【パターンC: 別のレジストラを使用している場合】

各サービスの DNS 管理画面から、Resend から提供された DNS レコードを以下の形式で入力してください：

【SPF レコード】
レコード種別: TXT
ホスト: @ (またはドメイン名そのもの)
内容: v=spf1 include:sendingdomain.resend.dev ~all

【DKIM レコード】
レコード種別: CNAME (または TXT)
ホスト: default._domainkey
内容: [Resend から提供される値]



▼ ステップ 5：DNS 設定の確認（Resend 側）

1. Resend ダッシュボードに戻る
   - Domains ページを表示

2. ドメインをクリック
   - 追加したドメインをクリック

3. 「Verify」ボタンを探す
   - DNS 設定が反映されると、青い「Verify」ボタンが表示されます
   - 数分～1時間かかる場合があります
   - 「Verify」ボタンをクリック

4. 確認完了
   ✅ "Domain verified successfully" と表示されたら成功です


▼ ステップ 6：Resend から API キーを取得

1. Resend ダッシュボードにログイン
   - https://resend.com にアクセス

2. 「API Keys」ページを開く
   - 左側メニューの「API Keys」をクリック

3. 新しい API キーを作成
   - 青い「Create API Key」ボタンをクリック

4. API キーを設定
   - 名前: "Production API Key" など分かりやすい名前
   - ✓ Email Sending にチェック
   - 「Create」をクリック

5. API キーをコピー
   ⚠️ このキーは 1 回だけ表示されます
   安全な場所（パスワード管理ツール等）にコピーしておいてください

   形式例：
   re_xxxxxxxxxxxxxxxxxxxxxxxxxxxx


▼ ステップ 7：メール送信元アドレスを決定

Resend で、メールを送信する際の「From」アドレスを決定します。

【オプション A: シンプルなメールアドレス（推奨）】
送信元: noreply@yourdomain.com

【オプション B: 名前付きメールアドレス】
送信元: Support Team <support@yourdomain.com>



▼ ステップ 8：システムに設定を入力

以下の情報を、システム管理者に伝えてください：

【設定項目】
項目：RESEND_API_KEY
値：Resend から取得した API キー
例：re_xxxxxxxxxxxxxxxxxxxxxxxxxxxx

項目：EMAIL_FROM
値：メール送信元アドレス
例：noreply@yourdomain.com

【システム管理者側での設定方法】
システム管理者は以下のファイルを編集して設定します：

「.env」ファイルに追加
RESEND_API_KEY=re_xxxxxxxxxxxxxxxxxxxxxxxxxxxx
EMAIL_FROM=noreply@yourdomain.com

または、システム環境変数として設定します。

すべてチェックできたら、セットアップ完了です！
